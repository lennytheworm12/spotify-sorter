# Mapping reference

Curated, non-exhaustive relationships for manual inspection. Membership is not a probability, a sonic measurement or a playlist decision.

## Broad families

| ID | Operational meaning |
| --- | --- |
| electronic | Electronic music lineage (does not imply club function or fast tempo) |
| hip_hop | Hip-hop lineage (does not assert rap vocals or instrumental role) |
| pop | Pop lineage (does not imply identical mood, production or use) |
| rnb_soul | R&B / soul umbrella (does not equate all R&B with soul or all substyles) |
